# 第一章 Untiy 简介
1. **渲染管线**是一系列操作的集合，负责将场景中的内容（模型、光照、材质等）最终呈现在屏幕上。具体操作包括：
    * 剔除（Culling） ：确定哪些物体在摄像机视野内，不可见的物体不参与渲染
    * 渲染（Rendering） ： 将可见物体绘制到屏幕上
    * 后期处理（Post-processing） : 对渲染结果进行后期特效处理

2. Untiy 项目视图文件夹：
    * Assets： 存放所有资源文件，包括纹理、网格、声音、代码等，而游戏对象指的是一个场景或某一个关卡中的物体，可以用游戏对象新建资源，也可以用资源新建游戏对象。
    * Packages： 存放所有包文件，包括插件、库、工具等。

3. Unity 层级视图：与项目视图类似，但是只会显示当前场景（可以理解为游戏关卡）所包含的分项。

4. Unity 中有两种摄像机：
    * 作为游戏对象的摄像机。
    * 虚拟的摄像机，场景中不是真实存在，决定了用户在场景视图中所能看到的内容。

5. 飞越模式即传统第一人称的方式来控制移动。移动鼠标控制方向， W A S D 在场景中沿着不同方向前进， Q E 控制整个场景的上下的移动。Shift 键可以用于加速。**场景视图右键单击进入飞越模式。**

# 第二章 游戏对象
1. 变换（transform）包括位置、旋转、缩放。可以在 insepector 中查看修改，也可以使用快捷键 Q W E S ...，需要注意的是旋转一个对象并不会在空间中进行移动，而是改变对象与那个空间的关系，即重新定义 x  y z 对于特定对象而言指向的是哪一个方向。

2. unity 中子对象的位置坐标是局部坐标，是相对于父对象而言，即以父对象为原点，建立坐标系。

# 第三章 模型、材质和纹理
1. Unity 中图形资源被分为：
    * 纹理：应用于 3D 对象的平面图像，相当于贴图，绘制 3D 对象。
    * 着色器：如何在模型表面绘制纹理。
    * 材质：应用于模型的着色器和纹理的容器。

    将纹理与着色器应用于材质以后，再将材质应用于模型。
