# 第一章 构造函数抽象
1. 即时编译(Just In Time,JIT):在程序运行过程中，将代码动态编译成机器码的技术。与之相对的是 AOT 编译技术，例如 C/C++，在程序运行之前，就把全部代码编译成机器码。

2. 浏览器常见组成部分：
	* Blink：解析 HTML CSS，计算页面布局和渲染
	* V8：解析并执行 javascript
	* 网络模块：发送 HTTP 请求
	* 其他功能

3. 为了把简单的概念组合起来形成更复杂的概念，语言应当提供一以下三种机制：
	- **基本表达式**：最简单的个体
	- **组合的方法**：可以从简单元素出发构造出复合元素
	- **抽象的方法**：将复合元素命名，从而将复合元素作为一个整体单元去操作

4. 运算符组合式（1 + 2）的求值：
	- 求值该组合式的各个子表达式，也就是上面的 1 和 2 的部分
	- 把运算符指代的那个函数（上面的加法运算）应用于有关的实参，也就是各个运算对象的值

5. 函数应用式（调用函数的表达式）的求值：
	- 求值各个子表达式，包括函数表达式（即函数的 return 语句）和各个实参表达式
	- 把得到的函数表达式的值应用于那些实参表达式的值
