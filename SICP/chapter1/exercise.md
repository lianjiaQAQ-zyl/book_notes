		return a >= c && b >= c

			: a >= b && c >= b
			? a * a + c * c
			: b * b + c * c; 
}

# 练习1.5
应用序求值时会先求出所有参数的值，再调用函数；正则序求值的时候先把函数体进行展开，只有真正需要某个参数的时候才会计算它。
所以对于这个例子，采用应用序求值的时候，会无限递归调用 p()，永远不会执行到 test 函数；而采用正则序求值的时候，会先进行展开，即 0 === 0 ？0 : p()，然后返回 0.
